# teamproject — сбор TikTok-данных по онлайн-школам

Основа — скрипты Рин (поиск → посты → комментарии → реплаи; картинки + OCR), из скрипта Маши
(`scrapping2.py`) взяты **дата создания аккаунта**, статистика автора/поста, субтитры и Whisper.
Всё собрано в один конвейер `pipeline.py`, который идёт по школам из `schools_plan.txt`.

## Файлы

| Файл | Что делает |
|---|---|
| **`pipeline.py`** | **Единая точка входа**: все школы из плана по очереди/параллельно → `ИТОГ_<школа>.xlsx`, `ИТОГ_ВСЕ_ШКОЛЫ.xlsx` |
| `schools_plan.txt` | План: одна строка = школа, её поисковые запросы и хэштеги (порядок = очередь) |
| `schools.txt` | Список школ и вариантов написания — для распознавания на слайдах и подсказки Whisper |
| `collect_tiktok_search_threads.py` | Поиск + хэштеги → дедуп → таблица постов → слайды/OCR → видео/Whisper → комментарии → реплаи (Рин, расширен) |
| `collect_tiktok_threads.py` | Комментарии + реплаи для конкретного поста (Рин, исправлен под текущий TikTok) |
| `collect_tiktok_images.py` | Слайды каруселей (Рин, исправлен) |
| `tiktok_fields.py` | Плоские поля поста: дата создания аккаунта (из ID), подписчики, лайки, просмотры, хэштеги, субтитры |
| `ocr_vlm.py` | Расшифровка слайдов нейросетью через API OpenRouter (ключ в `openrouter_key.txt`) |
| `transcribe_whisper.py` | Речь из видео через faster-whisper (по коду Маши), кэш `transcript.whisper.json` |
| `export_comments_table.py` | Таблица комментариев и реплаев (одна строка = один комментарий) |
| `paddle_ocr_folder.py`, `scrapping2.py`, `TIKTOK_*_README.txt` | Исходные файлы Рин и Маши |

## Рабочий процесс — 4 кнопки (Mac: `.command`, Windows: `.bat`)

| Шаг | Кнопка | Что делает |
|---|---|---|
| 1 | **`ПЕРЕПИСЬ.command`** / `CENSUS.bat` | Все посты по школам из `plan_census.txt` за окно (год): запросы + хэштеги + ленты авторов, таблица постов, слайды каруселей, лист «Покрытие». Нужны аккаунты TikTok. |
| 2 | **`ТРАНСКРИПТЫ.command`** / `TRANSCRIPTS.bat` | По ссылкам из таблиц: yt-dlp качает ролик → 5 кадров → **Whisper large-v3 (GPU)** → текст с кадров через API → видео удаляется. Без браузера и аккаунтов. `--all` — все посты с упоминанием школы, по умолчанию выборки. |
| 3 | `КОММЕНТАРИИ.command` / `COMMENTS.bat` | Комментарии и реплаи (200 на пост) по выборкам школ. Нужны аккаунты TikTok. Можно позже. |
| 4 | **`ТАБЛИЦЫ.command`** / `TABLES.bat` | Пересобрать `ИТОГ_<школа>.xlsx` и `ИТОГ_ВСЕ_ШКОЛЫ.xlsx` из всего собранного — в любой момент. |

Шаги 2 и 3 можно запускать одновременно. Всё перезапускаемое: повторный запуск продолжает с места.
Первый запуск на новом компьютере: `1_setup.command` (окружение) и `2_login.command` (аккаунты TikTok, только для шагов 1 и 3).

Служебное: `СТАТУС.command` — где сейчас сбор; `0_update_from_github.command` — обновить код; `0_unlock_account.command` — снять блокировки аккаунтов;
`ГЛУБИНА.command` — старый путь (видео через браузер + фоновый Whisper), нужен только если yt-dlp не качает;
`НА_НОЧЬ.command` / `NIGHT.bat` — движок, который вызывают остальные кнопки.

Секреты (`github_token.txt`, `openrouter_key.txt`), данные (`cases/`), логи и `pipeline_state.json` в git не попадают.

## Конвейер

```
python pipeline.py                     # все школы из плана, не больше 500 постов на школу
python pipeline.py --parallel 0        # потоков = аккаунтов в пуле (4 аккаунта = 4 школы одновременно)
python pipeline.py --only Умскул,Фоксфорд
python pipeline.py --test              # пробный: 5 результатов на источник, 3 поста, 10 комментариев
python pipeline.py --final-only        # только пересобрать итоговые книги из уже собранного
python pipeline.py --redo              # пройти заново и уже готовые школы
python pipeline.py --max-posts 1000 --comments 500 --whisper off
```

Для каждой школы: поиск по запросам + ленты хэштегов → дедуп → отбор (сначала посты с упоминанием школы
в описании/хэштегах/авторе, не больше `--max-posts`) → таблица постов (автор, **дата создания аккаунта**,
статистика, хэштеги, по каким запросам найден) → карусели: слайды + расшифровка через API (колонки «Текст
со слайдов», «Школы на слайдах», «Контекст слайдов», «Сравнение школ на слайдах») → видео: субтитры TikTok +
скачивание + Whisper («Транскрипт (Whisper)», «Источник транскрипта»; `--whisper missing|all|off`) →
комментарии верхнего уровня + реплаи → `ИТОГ_<школа>.xlsx` (листы Посты / Комментарии и реплаи / Сводка).
После всех школ — `ИТОГ_ВСЕ_ШКОЛЫ.xlsx`.

Готовые школы помечаются в `pipeline_state.json`; при повторном запуске пропускаются, уже собранные
комментарии не собираются повторно. Данные школы — `cases/<школа>/` (JSON, таблицы прогонов, сырые
комментарии в `raw/posts/<id>/`), медиа — `cases/tiktok_media/raw/posts/<id>/` (слайды, `video.mp4`, кэши расшифровок).

## Важно

- Дата создания аккаунта вычисляется из ID пользователя (старшие 32 бита — unix-время); для аккаунтов до 2014 поле пустое.
- Поиск TikTok — механизм выдачи, не случайная и не полная выборка; поиск отдаёт только видео, карусели приходят из лент хэштегов.
- Автоматических ретраев нет; задержки консервативные.
